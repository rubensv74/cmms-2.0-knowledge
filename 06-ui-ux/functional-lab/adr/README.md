# ADR — CMMS 2.0 Functional Lab

Este directorio registra las decisiones arquitectónicas aprobadas para la arquitectura v2.

| ADR | Decisión | Estado |
|---|---|---|
| ADR-001 | Identidad Functional Lab + shell completo CMMS 2.0 | Aprobado |
| ADR-002 | Navegación dual: producto + Process Rail metodológico | Aprobado |
| ADR-003 | Pantallas por objeto/proceso, no por ahorro de pantallas | Aprobado |
| ADR-004 | AnalysisCase como raíz y maestros read-only durante análisis | Aprobado |
| ADR-005 | Borrador automático + confirmación explícita de decisiones | Aprobado |
| ADR-006 | Autoridad humana separada de cálculo/recomendación | Aprobado |
| ADR-007 | Backend desacoplado con contratos Azure SQL-ready | Aprobado |
| ADR-008 | Componentes premium reutilizables y Component Library-ready | Aprobado |
| ADR-009 | Desktop+tablet responsive y localización ES/EN future-ready | Aprobado |
| ADR-010 | Colaboración multirrol, trazabilidad e IA como recomendación | Aprobado |

Regla: una nueva decisión solo genera otro ADR cuando pueda obligar a rediseñar pantallas, contratos, persistencia, navegación, autoridad o componentes fundacionales.
