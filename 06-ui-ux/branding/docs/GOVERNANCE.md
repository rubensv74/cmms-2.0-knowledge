# Gobierno y versionado del branding CMMS

## Fuente de verdad

Esta librería debe vivir versionada junto al producto. Los consumidores deben referenciar los activos publicados, no crear copias modificadas dentro de cada módulo.

## Versionado

- PATCH: correcciones técnicas sin cambio visual.
- MINOR: nuevos iconos o activos compatibles.
- MAJOR: cambio de logotipo, paleta o reglas que altere identidad existente.

## Convenciones

- Prefijo CSS/tokens: `cmms-` / `CMMS_`.
- SVG funcionales: nombres semánticos en inglés para facilitar uso técnico.
- Documentación de uso: español.
- No guardar fuentes binarias dentro del pack.
