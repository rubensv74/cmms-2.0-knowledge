# Catálogo de activos CMMS

## Logotipos

- `cmms-logo-horizontal-color.svg` — principal sobre fondo claro.
- `cmms-logo-horizontal-on-dark.svg` — principal sobre fondo oscuro.
- `cmms-logo-horizontal-no-tagline.svg` — versión compacta.
- `cmms-logo-stacked-color.svg` — composición vertical.
- `cmms-isotype-color.svg` — isotipo oficial con gradiente.
- `cmms-isotype-mono-navy.svg` — reproducción monocroma navy.
- `cmms-isotype-mono-white.svg` — reproducción monocroma clara.
- `cmms-app-icon-dark.svg` — icono de aplicación.
- `cmms-favicon.svg` — favicon SVG.

## Iconos funcionales

Dashboard, órdenes de trabajo, activos, mantenimiento, inventario, compras, reportes, configuración, calendario, alertas, usuarios, checklist, herramientas, edificios, vehículos, fluidos, energía, filtros, búsqueda, almacén, seguridad, costes, analítica y documentos.

Todos los iconos usan `currentColor`, por lo que el consumidor controla el color sin modificar el archivo.

## Tokens

- `cmms-brand-tokens.json` — fuente neutral.
- `cmms-brand.css` — variables CSS.
- `CMMSBrandTokens.powerfx.txt` — equivalencias base para Power Apps.
