# CMMS — Reglas de uso de marca

## 1. Jerarquía de marca

1. **Isotipo**: hexágono + llave. Es el elemento distintivo.
2. **Wordmark**: `CMMS`.
3. **Tagline**: `Gestiona. Mantiene. Optimiza.` Es opcional y desaparece en tamaños pequeños.

## 2. Degradado del hexágono

- Permitido únicamente en el isotipo, icono de aplicación y elementos hero excepcionales que representen explícitamente la marca.
- No usar el gradiente como fondo estándar de botones, KPIs o tarjetas.
- Mantener la dirección aproximada de 135° y los tres stops oficiales.

## 3. Fondos

- Fondo claro: wordmark navy y isotipo color.
- Fondo oscuro: wordmark blanco y símbolo interior blanco.
- Evitar imágenes o fondos con poco contraste bajo el logotipo.

## 4. Tamaños mínimos

- Logo horizontal digital: recomendado ≥ 120 px de ancho.
- Isotipo digital: recomendado ≥ 24 px; usar favicon simplificado por debajo.
- En interfaces, no mostrar el tagline si el bloque del logo es menor de 180 px de ancho.

## 5. Iconografía

- Grid: 24×24.
- Stroke: 1.8.
- Extremos y uniones redondeados.
- Color por defecto: navy/slate; azul para selección; verde solo para estados positivos.
- No aplicar el gradiente de marca a iconos funcionales.

## 6. Tipografía

Montserrat Semibold/Bold para títulos y acciones importantes; Medium/Regular para contenido. Evitar mezclar familias sin una razón funcional.

## 7. Usos incorrectos

No deformar, rotar, recolorear arbitrariamente, añadir sombras fuertes, cambiar la geometría, separar las piezas del símbolo ni alterar el orden del tagline.
