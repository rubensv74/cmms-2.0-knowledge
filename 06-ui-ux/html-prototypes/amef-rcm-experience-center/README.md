# AMEF–RCM Experience Center

Paquete integrado de demostración funcional para CMMS 2.0.

## Ejecución

Descomprimir el paquete y abrir `index.html`. No requiere servidor ni dependencias externas.

## Estructura

- `index.html`: punto único de entrada.
- `mapa-maestro/`: 17 etapas y contratos funcionales.
- `prototipos/01-*` a `05-*`: recorrido AMEF–RCM completo.
- `docs/`: documentación de público general, coherencia con reuniones y guía de presentación.
- `releases/`: ubicación prevista para el ZIP autocontenido de distribución.

## Estado

Demostración conceptual. Los datos, costes, escalas, estados y reglas son ejemplos para facilitar la validación funcional. No constituye un AMEF–RCM aprobado ni una instrucción operativa.
