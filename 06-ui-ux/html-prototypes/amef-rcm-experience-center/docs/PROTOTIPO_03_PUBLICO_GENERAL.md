# Prototipo 3 — Tomar la decisión RCM

Este prototipo muestra cómo se utiliza un árbol de decisión para elegir la estrategia más adecuada ante cada modo de fallo. El sistema explica el recorrido, pero la decisión sigue perteneciendo al equipo técnico.

### Qué verá el usuario

- Clasificación de consecuencias.
- Preguntas secuenciales inspiradas en SAE JA1012.
- Comparación de tareas por condición, restauración, sustitución, búsqueda de fallos, rediseño y operación hasta fallo.
- Uso del intervalo P–F.
- Escenarios que modifican frecuencia, parada y detectabilidad.
- Recomendación con condiciones de validez.

### Mensaje principal

RCM no es un algoritmo autónomo. Es una forma estructurada de justificar por qué una estrategia es aplicable y efectiva.

### Decisiones pendientes

Árbol corporativo definitivo, evidencia exigida, tratamiento de consecuencias combinadas y autoridad de la decisión final.
