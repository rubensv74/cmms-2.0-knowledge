## Interpretación de estados

- **Validado en reunión:** principio o necesidad expresamente comentada.
- **Propuesta conceptual:** forma concreta en que el HTML representa esa necesidad.
- **Pendiente de decisión:** regla, dato o integración que deberá validarse antes de la especificación para IT.
