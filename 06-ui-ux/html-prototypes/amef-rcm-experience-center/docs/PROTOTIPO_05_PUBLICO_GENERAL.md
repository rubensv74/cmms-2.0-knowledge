# Prototipo 5 — Gobernar y mejorar

Este prototipo explica cómo se revisa, aprueba y mantiene vivo el análisis. Permite reconstruir la justificación de cada tarea, detectar incoherencias y utilizar los resultados reales para generar nuevas versiones.

### Qué verá el usuario

- Matriz de trazabilidad integral.
- Validador de calidad AMEF–RCM.
- Gestión de discrepancias multidisciplinares.
- Aprobaciones por rol y versión.
- Informe ejecutivo con acceso al detalle.
- Dashboard de seguimiento y cola de revisión.

### Mensaje principal

AMEF–RCM no termina cuando se publica el plan. Las hipótesis deben compararse con fallos, hallazgos, costes y cambios reales.

### Decisiones pendientes

Workflow de aprobación, firmas, permisos, versionado, KPIs de efectividad y condiciones que disparan una revisión.
