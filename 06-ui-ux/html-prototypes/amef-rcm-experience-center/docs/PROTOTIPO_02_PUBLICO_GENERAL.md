# Prototipo 2 — Evaluar el riesgo

Este prototipo convierte los modos de fallo identificados en un análisis AMEF. El objetivo es comprender qué ocurre, cuáles son las consecuencias, qué controles existen y qué temas necesitan atención prioritaria.

### Qué verá el usuario

- Una mesa de trabajo AMEF.
- Severidad, ocurrencia y detectabilidad.
- Riesgo y NPR como indicadores complementarios.
- Una matriz de criticidad interactiva.
- Excepciones y observaciones metodológicas.
- Un gate de preparación hacia RCM.

### Mensaje principal

El NPR no debe utilizarse como única respuesta. Una consecuencia de seguridad, medioambiental u oculta puede elevar la prioridad aunque el número calculado sea inferior.

### Decisiones pendientes

Escalas corporativas, autoridad de aceptación del riesgo, reglas de sobreclasificación y evidencia mínima requerida.
