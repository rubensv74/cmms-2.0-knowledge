Reglas ADR y opciones de configuración

Consecuencias funcionales de cada decisión del paso 3.

Relaciones padre-hijo

Activada: permite construir composición física mediante ParentAssetCode. Desactivada: todos los activos quedan independientes y se pierde el contexto de conjunto.

Herencia de ubicación

Activada: un hijo sin LocationCode propio utiliza la ubicación del activo raíz. Desactivada: cada activo físico debe vincular una ubicación FLH válida.

Taxonomía y criticidad obligatorias

Activada: bloquea registros incompletos. Desactivada: permite borradores, pero reduce calidad de mantenimiento, reporting y fiabilidad.

Modelo de criticidad

Define los valores permitidos. Cambiar de A/B/C a otra escala requiere mapeo para conservar comparabilidad histórica.

Ubicación propia o heredada

Mixta admite ambos casos; propia obligatoria exige LocationCode en cada activo; herencia obligatoria concentra todo el árbol bajo la ubicación raíz.

Relación por defecto

Solo propone un valor inicial. El usuario debe cambiarlo cuando corresponda a AuxiliarySystem, Instrumentation, DrivenBy u otra relación aprobada.

Máximo de padres físicos = 1

Evita árboles ambiguos: cada activo pertenece a un único padre físico, aunque pueda mantener otras relaciones lógicas no jerárquicas.

Cardinalidad de activos raíz

No se configura aquí. El CMMS aplica EffectiveAssetRootPolicy procedente de la FLH para cada LocationCode.

Columnas de Asset Classification Template

La hoja de carga se genera vacía; los catálogos y validaciones se incorporan como referencias protegidas.

LocationCode

Ubicación FLH activa a la que se vincula el activo raíz.

LocationDescription

Descripción informativa de la ubicación seleccionada.

LevelNumber / DisplayName

Nivel numérico y etiqueta visible heredados de la FLH.

FunctionalRole

Rol corporativo opcional de la ubicación; no gobierna la jerarquía.

EffectiveAssetRootPolicy

Regla final NONE, SINGLE o MULTIPLE que se validará para el LocationCode.

AssetCode / AssetDescription

Identificador único y descripción del nuevo activo raíz ADR.

EquipmentTypeCode

Hoja taxonómica seleccionada del catálogo publicado.

Discipline, Typology, Family, Subfamily

Ruta calculada desde EquipmentTypeCode; no debe escribirse manualmente.

Criticality

Valor permitido por el modelo de criticidad publicado.

ClassificationStatus

Resultado del procesamiento: pendiente, válido o rechazado con motivo.
