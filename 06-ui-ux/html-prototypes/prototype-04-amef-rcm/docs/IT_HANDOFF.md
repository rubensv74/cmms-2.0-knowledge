# Handoff a IT

Decisiones productivas que no bloquean la demo:

| Tema | Contrato funcional de la demo | Decision de IT |
|---|---|---|
| Maestros | Activo, FLH, taxonomia y ADR distintos | Sistemas maestros e IDs |
| Acceso | Autor, revisor y rol simulados | Identidad, permisos y segregacion |
| Persistencia | Estado local reiniciable | Tecnologia, volumen y concurrencia |
| Integracion | Salidas y eventos conceptuales | APIs, patron y errores |
| Versionado | Publicada inmutable y nueva revision | Snapshot y comparacion fisica |
| Workflow | Cinco etapas indicadas | Motor, orden, quorum y delegacion |
| Riesgo | Matriz 5x5 simulada/versionada | Matriz oficial y riesgo residual |
| RCM | Arbol versionado y trazable | Logica corporativa y gobierno |
| Contexto | Criticidad y operacion simuladas | Fuentes maestras |
| Evidencia | Metadatos/enlaces simulados | Repositorio, formatos y retencion |
| Estrategia | Recomendacion separada | Conversion a Job Plans/estrategias |
| Feedback | Enlace conceptual | Retorno desde WO, condicion y costes |
| Auditoria | Timeline simulado | Firma, retencion y no repudio |
| Idioma | Espanol | Multidioma |

Eventos funcionales candidatos: borrador guardado, enviado a revision, etapa devuelta/aprobada, revision publicada/siguiente creada, aplicabilidad validada y tratamiento propuesto. Nombre, transporte y payload corresponden a IT.
