# CMMS 2.0 Knowledge Repository

Repositorio documental corporativo del programa CMMS 2.0.

## Objetivo

Mantener una unica fuente de verdad para la vision, decisiones, requisitos funcionales, modelo de datos, flujos, reuniones, prototipos y recursos de referencia.

## Navegacion rapida

- [Estado actual](PROJECT_STATUS.md)
- [Roadmap](ROADMAP.md)
- [Indice maestro](MASTER_INDEX.md)
- [Historial de cambios](CHANGELOG.md)
- [Mapa visual del producto](04-diagrams/mermaid/cmms-product-map.md)

## Principios

1. Toda decision relevante debe quedar documentada.
2. Toda reunion debe generar una nota independiente.
3. Los recursos recibidos se conservan sin modificacion en `08-resources`.
4. Los diagramas Mermaid se almacenan en Markdown para su renderizado directo en GitHub.
5. `PROJECT_STATUS.md` debe reflejar siempre el estado real del proyecto.
